# ⚔️ TLoN Калькулятор

<a href="https://hakimotox.github.io/TLONCalc/" target="_blank">TLoN Калькулятор</a>

**TLoN Калькулятор** — это интерактивный веб-инструмент для расчёта боевых параметров в игре **The Legend Of Neverland (TLoN)**. Он помогает оптимизировать статы, учитывая все ключевые механики: крит, блок, иммунитеты и снижения урона.

## 🚀 Возможности

- **Двусторонний расчёт** — считает ваш урон по противнику и урон противника по вам.
- **Полный учёт механик**:
  - `net_crit = крит - иммунитет_к_криту`
  - `net_block = блок - уничтожение`
  - **Конкуренция шансов**: если `net_crit + net_block > 100%`, шансы пересчитываются пропорционально.
  - Игнор блока, подавление лечения блока, снижение УРН.
- **Анализ прокачки** — показывает, сколько % стата нужно добавить, чтобы достичь целевого среднего урона.
- **Автосохранение** — все данные сохраняются в браузере (localStorage) и восстанавливаются при перезагрузке.
- **Тёмная тема** — для комфортной работы в любых условиях.
- **Экспорт/Импорт** — сохранение билдов в JSON-файлы и загрузка обратно.

## 📊 Формулы

### Шансы
```

net_crit = max(крит - иммунитет_к_криту, 0)
net_block = max(блок_противника - уничтожение, 0)
total = net_crit + net_block

if total <= 100:
final_crit = net_crit
final_block = net_block
final_normal = 100 - total
else:
final_crit = net_crit / total * 100
final_block = net_block / total * 100
final_normal = 0

```

### Урон
```

final_crit_dmg = max(150 + УРН_крита - снижение_УРН_крита, 150)
final_block_dmg = max(50 - снижение_УРН_блока, 0)

```

## 🎮 Использование

1. **Введи свои статы** в левой колонке ("Вы атакующий").
2. **Введи статы противника** в правой колонке ("Противник атакующий").
3. **Настрой защитные статы** в нижних блоках.
4. **Результаты** обновляются автоматически:
   - Шансы крита, блока и обычного удара.
   - Средний урон (в % от базового).
5. **Анализ прокачки** покажет, сколько статов нужно добавить для достижения цели.
6. **Сохрани билд** в файл или используй автосохранение в браузере.
