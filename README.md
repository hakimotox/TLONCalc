# ⚔️ TLoNKit — Набор инструментов для The Legend of Neverland

**TLoNKit** — это коллекция веб-инструментов для игры **The Legend Of Neverland (TLoN)**, созданная для удобства игроков. Включает в себя Калькулятор боевых параметров и Симулятор эмблем гильдии.

Переход к проекту: [TLoN Kit](https://hakimotox.github.io/TLoNKit/)

## 🛠️ В состав набора входят:

### 1. 📊 Калькулятор крита, блока и урона
Интерактивный инструмент для глубокого анализа боевых параметров.
*   **Двусторонний расчёт:** Мгновенно вычисляет ваш урон по противнику и урон противника по вам.
*   **Все ключевые механики:** Учитывает крит, блок, иммунитеты, уничтожение, игнор блока, снижение УРН и другие статы.
*   **Конкуренция шансов:** Автоматически корректно обрабатывает ситуацию, когда сумма шансов крита и блока превышает 100%.
*   **Анализ прокачки:** Показывает, сколько % стата нужно добавить, чтобы достичь целевого среднего урона.
*   **Автосохранение и Экспорт:** Все данные сохраняются в браузере, а билды можно выгружать в JSON-файлы.

### 2. 🛡️ Симулятор эмблем гильдии
Визуальный планировщик для подбора эмблем гильдии.
*   **Разделение по гербам:** Все эмблемы строго распределены по трём гербам (Красный, Синий, Зелёный).
*   **Интеллектуальная логика:** Позволяет выбирать до 3 эмблем в каждом гербе, автоматически вычисляя сумму максимальных значений (по одному из трёх цветов) и блокируя выбор, если она превышает 30.
*   **Сохранение билдов:** Можно сохранять понравившиеся комбинации в историю, давать им названия, загружать и удалять их.
*   **Визуализация:** В реальном времени показывает итоговые очки по каждому гербу, список выбранных эмблем и их описания.

## 🎮 Как использовать

1.  Перейдите к проекту [TLoN Kit](https://hakimotox.github.io/TLoNKit/).
2.  Выбери нужный инструмент:
    *   Нажми **"📊 Калькулятор"** для анализа боевых параметров.
    *   Нажми **"🛡️ Симулятор"** для планирования эмблем гильдии.
3.  В каждом инструменте вводи данные или выбирай эмблемы — результаты обновляются автоматически.
4.  Используй автосохранение или функции экспорта/импорта для хранения своих билдов.
